# OBS Key Vault

Плагин для OBS Studio 31/32 (Windows x64): док-панель со списком ключей трансляций и переключение на следующую трансляцию **одной горячей клавишей** — плагин сам останавливает стрим, ставит следующий ключ и запускает стрим заново (пауза ~1–3 с).

## Установка

1. Скачайте `obs-key-vault-<версия>-windows-x64-Installer.exe` из [Releases](../../releases) или из артефактов последней сборки в [Actions](../../actions).
2. Закройте OBS и запустите установщик. Плагин ставится в `C:\ProgramData\obs-studio\plugins\obs-key-vault\`.
3. Запустите OBS → меню **Док-панели** → **Key Vault**.

## Использование

1. В **Настройки → Трансляция** выберите «Настраиваемый» сервис и укажите сервер (например, `rtmp://vsu.mycdn.me/input/`). Ключ там можно не заполнять.
2. В панели Key Vault нажмите **+** для каждой трансляции, впишите название и вставьте ключ (двойной клик по ячейке). Порядок строк = порядок трансляций, менять кнопками ↑ ↓.
3. В **Настройки → Горячие клавиши** найдите раздел Key Vault и назначьте:
   - **Key Vault: Следующая трансляция** — стоп → следующий ключ → старт;
   - **Key Vault: Трансляция 1…5** — сразу на конкретный ключ.
4. Большая кнопка «⏭ Следующая: …» в панели делает то же, что хоткей. Кнопка ▶ в строке — в эфир с ключом этой строки.

Если стрим не идёт, «Следующая» просто ставит ключ и запускает стрим. На последней трансляции списка «Следующая» ничего не делает. Пока идёт переключение, повторные нажатия игнорируются.

Ключи хранятся в `%APPDATA%\obs-studio\plugin_config\obs-key-vault\keys.json` (так же открыто, как OBS хранит собственный ключ в `service.json`).

## Проверка без выхода в эфир

Запустите локальный RTMP-сервер [MediaMTX](https://github.com/bluenviron/mediamtx), в OBS укажите сервер `rtmp://localhost/live`, а в панель добавьте ключи `test1`, `test2`, `test3`. При нажатии хоткея в логе MediaMTX путь публикации будет меняться `live/test1 → live/test2 → live/test3`.
